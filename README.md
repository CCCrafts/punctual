# newcal (codename)

Edge-native scheduling — an open, single-team scheduler that runs entirely on
Cloudflare Workers. Booking pages render at the edge (<100 ms TTFB worldwide);
self-hosting is one `wrangler deploy` into your own Cloudflare account, $0 on
the free tier.

> **Status:** pre-M0. Product name TBD — "newcal" is a working codename.

## The pledge

The open-source version is complete for a single team — forever. No seat
limits, no gated scheduling features, no "non-production use" clauses.
MIT makes this promise irrevocable: what we ship can never be taken back.
