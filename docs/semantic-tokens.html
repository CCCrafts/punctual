Slot states

The booking flow's own state machine (src/core/slot-state.ts). held and booked are visually distinct from available without the accent (meridian/signal green) — that hue is reserved for the guest's own current pick (hover/selected), never a system state. held reads as "in flux" (warning hue, solid border); booked reads as "settled" (neutral, struck-through time); past and outside-notice-window are both neutral but stay distinguishable from each other structurally — see the border style/opacity on each — so the difference survives greyscale, not just colour.
